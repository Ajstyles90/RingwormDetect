About the System

About

What is this system?

This system is an AI-assisted ringworm detection application developed as a Computer Science project. It uses a trained YOLOv11s model to analyze skin images for visual indications of ringworm and presents the results with confidence scores and bounding boxes.

It is intended as an educational and research tool to demonstrate object detection applied to a real-world dermatological concern.

How does it work?

  1. 1 User uploads an image
  2. 2 Image is sent for processing
  3. 3 YOLOv11s analyzes the image
  4. 4 Detection results are returned
  5. 5 Results are presented visually
